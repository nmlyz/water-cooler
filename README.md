water-cooler writes one line to a text file: a one-line joke about office life. The line was picked from 36 candidates by pairwise judging against the brief — a Slack status left on "In a meeting" for three days, closed on the self-own that nobody noticed, its owner included. The joke is built from two clauses: the first sets a status everyone in an office recognises, the second turns three days of silence into a punchline that lands on its last two words. No setup needs explaining, no office cliché carries it, and nothing after the punchline explains the joke.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run. The line is 85 characters, a single line. The program checks the result against the entry gate (length, single line, no leading or trailing space, exact judged length) before writing it, then reads the file back to confirm the bytes match.
